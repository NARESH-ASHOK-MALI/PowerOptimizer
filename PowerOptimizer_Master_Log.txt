================================================================================
  SECTION 6: POST-V8.0 LOGIC HOTFIXES (Jul 05, 2026 - 17:30 IST)
================================================================================

  Following the initial v8.0 release, a deep architectural review identified 
  and resolved three critical logic bugs:

  1. CURRENT_MODE Persistence Bug (Fixed):
     The wake-triggered scheduled task spawned a fresh cmd process where the 
     in-memory CURRENT_MODE variable was undefined, causing it to blindly 
     re-apply Ultra Saver settings and corrupt state.
     FIX: Mode state is now written to `%~dp0.powermode.state` safely on 
     selection and read back reliably on script startup and re-apply.

  2. Modern Standby (S0ix) Trigger Reliability (Fixed):
     The Vivobook uses Modern Standby, which doesn't consistently trigger the 
     Legacy S3 Event ID 1.
     FIX: Added two parallel scheduled tasks to trigger on Modern Standby 
     Resume (EventID 507) and Workstation Unlock (EventID 4801).

  3. Nested !errorlevel! Expansion (Fixed):
     powercfg fallback blocks in Performance modes used `%errorlevel%` which 
     failed to evaluate inside parenthesized blocks.
     FIX: Swapped to `!errorlevel!` for delayed expansion accuracy.
